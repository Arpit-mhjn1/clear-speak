# ClearSpeak: Real-Time Sign Language Translation
### The Global Problem: 
Severe communication barriers for the 430 million people worldwide with disabling hearing loss. 
### The Project: 
A web application that uses the webcam and standard browser-based machine learning (like MediaPipe or TensorFlow.js) to track hand joints and facial expressions. It translates standard sign language gestures into spoken audio and text in real-time, allowing seamless conversation between deaf individuals and non-signers. 
### Why it Wins:
<li>Impact: Pure accessibility and inclusion.</li>
<li>Tech Flex: High-framerate pose estimation and sequence prediction in the browser.</li>
<li>Demo: Getting up on stage, signing a full sentence into the webcam, and having the computer instantly speak the sentence aloud to the audience.</li>
